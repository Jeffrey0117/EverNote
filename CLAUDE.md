# Evernote

Astro-based technical notes blog (`vibe-notes-blog`) with AI-assisted writing and auto-generated notes from git commits. Deployed to GitHub Pages at `/Evernote`.

## Stack
- Astro v5 (static site generator), TypeScript (`astro/tsconfigs/strict`, `@/*` → `src/*`)
- Content: Markdown/MDX (`@astrojs/mdx`), Shiki syntax highlighting (`github-light`, wrap)
- Pagefind v1 — full-site search (built into `npm run build`)
- `@astrojs/sitemap` (integration) + `@astrojs/rss` (RSS feed)
- Helper scripts: Node.js `.cjs` (git-hook note generation, calls Claude API)

## Directory structure

```
src/
  layouts/
    BaseLayout.astro    ← base template (SEO, OG/Twitter tags, search, taglines)
    PostLayout.astro    ← article layout
    NoteLayout.astro    ← note layout (shows "筆記" badge)
  pages/
    index.astro         ← home (article list, pagination, category filter)
    about.astro
    rss.xml.ts          ← RSS feed (posts + notes)
    posts/              ← Markdown articles (curated, opinionated)
    notes/              ← Markdown notes (auto-generated from git hooks)
      index.astro       ← notes list page
  styles/
    global.css          ← global styles (CSS variables for theme)
scripts/
  generate-note.cjs     ← analyze git diff → Claude API → technical note
  install-hook.cjs      ← install post-commit git hook into other repos
public/                 ← favicon, robots.txt, og-default.png
dist/                   ← build output (static files)
*.bat                   ← find-topics / write-article / move-articles (AI writing flow)
```

## Key concepts

- **Posts vs Notes**: `/posts` = curated articles (PostLayout); `/notes` = technical notes/debug logs, usually auto-generated (NoteLayout). Both included in RSS.
- **Categories**: Articles auto-classified by `tags` frontmatter into 技術 / 觀念 / 專案 / 工具.
- **Frontmatter**: Posts require `layout, title, date (YYYY-MM-DDTHH:mm), description, tags`; optional `pinned`. Notes require `layout, title, date`; optional `tags, source, autoGenerated`.
- **AI writing tools** (`.bat` + Gemini): division of labor to save tokens — Claude extracts raw material from chat context, Gemini reads full spec and writes the article. Specs live in `src/pages/posts/project-guide.md` (writing rules) and `context-spec.md` (raw-material checklist).
- **Git Hook auto-notes**: `node scripts/install-hook.cjs --target <repo>` installs a post-commit hook in any project; on commit it diffs, calls Claude API, generates a note, and commits to this repo's `notes/`. Requires `ANTHROPIC_API_KEY` env var. `.note-history.json` tracks generated notes to avoid duplicates.
- **Telegram Bot writing**: ClaudeBot `/write` (post) and `/write-note` (note) commands generate, preview, then commit/push.
- **Theming**: edit CSS variables in `src/styles/global.css` (`--bg-primary`, `--text-primary`, `--accent`, fonts).
- **Image rules** (AI-generated articles, see SPEC.md): prefer Unsplash permanent URLs (`images.unsplash.com/photo-...?w=800&q=80`); never Google Image search or arbitrary site URLs.

## Commands

```bash
npm install                        # install deps
npm run dev                        # astro dev server
npm run build                      # astro build + pagefind search index
npm run preview                    # preview built site

# Git-hook note generation (needs ANTHROPIC_API_KEY)
node scripts/generate-note.cjs --repo <path> --dry-run    # preview only
node scripts/generate-note.cjs --repo <path>              # generate note
node scripts/generate-note.cjs --repo <path> --auto-commit
node scripts/install-hook.cjs --target <repo>             # install hook in another project
```

No test setup or linter configured.

## Deployment
- GitHub Actions auto-deploys to GitHub Pages on push to `main`. Build output in `dist/` (also deployable to Vercel / Netlify / Cloudflare Pages / any static host).
- `astro.config.mjs`: `site: https://jeffrey0117.github.io`, `base: /Evernote` — keep `base` prefix on internal asset/image links.
