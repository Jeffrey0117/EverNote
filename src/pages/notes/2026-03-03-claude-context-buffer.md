- 擴大了 `MAX_STORE_LENGTH`，從 800 增加到 1500，以儲存更多的上下文資訊，可能有助於改善 Claude 模型在對話中的表現。
- 在 prompt 中加入了 `[前次回覆參考]`，當使用者回覆較短的訊息時，將上次的回覆作為參考資訊提供給 Claude 模型，以幫助模型更好地理解使用者的意圖。
- 根據使用者回覆的內容是否為肯定語氣，提供了不同的 hint，以引導 Claude 模型的回覆方式。如果使用者回覆是肯定語氣，則提示模型繼續執行；否則，提示模型使用上次的回覆作為參考。
