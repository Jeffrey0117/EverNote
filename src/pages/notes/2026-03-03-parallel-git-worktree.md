- 引入 Git worktree 作為平行處理的基礎，每個任務都在獨立的 worktree 中進行，避免互相干擾。
- 實作任務狀態追蹤機制，包括確認、執行中、完成、錯誤等狀態，並透過 Telegram 訊息即時更新進度。
- 提供自動合併功能，將完成的任務合併回主分支，並處理合併衝突。
- 實作 smart detection 功能，可以從訊息中自動偵測平行任務的候選者，並提供快速建立平行任務的選項。
