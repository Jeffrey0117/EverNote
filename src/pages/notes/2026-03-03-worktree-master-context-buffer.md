- 引入 `worktree-sync.ts`，實現在程式啟動時自動將 worktree branch 與 master branch 同步，確保 worktree 分支是最新的，這對於在 worktree 中運行的 bot 來說很重要，因為 master 分支可能包含重要的修正。
- 使用 `ensureWorktree`、`syncFromMain` 等函數來確保 worktree 存在並執行同步操作，並處理同步過程中的錯誤和衝突。
- 擴大 `MAX_STORE_LENGTH`，增加 `lastResponses` 中儲存的 context 長度，這有助於提供更豐富的上下文給 AI 模型，從而提升回應品質。
