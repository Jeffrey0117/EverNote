- 新增 `clip` plugin：引入新的 `clip` plugin，提供 `/save`、`/recall`、`/unsave` 指令，讓使用者可以儲存常用的訊息片段，方便日後快速取用。
- `json-file-store` 工具：使用 `createJsonFileStore` 建立輕量級的 JSON 檔案儲存，用於儲存每個 chat 的 clip 訊息。這是一種簡單的資料持久化方式，適合儲存少量、結構化的資料。
- Telegram 訊息靜音：在 `queue-processor.ts` 中為 Telegram 訊息新增 `disable_notification: true` 選項，用於長時間運行的任務，避免過多的通知打擾使用者。
